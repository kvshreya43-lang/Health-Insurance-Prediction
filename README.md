# 🏥 Medical Insurance Cost Prediction

## 📌 Project Overview

This project predicts medical insurance charges using Machine Learning (Linear Regression).

The application takes user information such as Age, Gender, BMI, Number of Children, Smoking Status and Region to estimate insurance charges.

---

## 📂 Dataset

Medical Cost Personal Dataset

Columns:

- age
- sex
- bmi
- children
- smoker
- region
- charges
